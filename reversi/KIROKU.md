# まるシマリバーシ 作業記録

最終更新：2026-10-18（段階1「盤だけ」完成、段階2「2台つなぐ」に着手）

遠くに住むおばあちゃんと小1の孫が、ビデオ通話で顔を見ておしゃべりしながら遠隔対戦するリバーシ。iPad の Safari で遊ぶ（Android の Chrome も可）。将来は Capacitor で包んで App Store／Google Play に出す。

## どこにあるか

| もの | 場所 |
|---|---|
| ゲーム本体 | https://amane1234567jp-crypto.github.io/kotoba-tane/reversi/ |
| 仕様書 | Claude Docs「まるシマリバーシ 仕様書（第1版）」 |
| 参考にしたアプリ | REVERSI REAL（盤の見た目・置ける場所のリング・最後の石の赤い光） |

## ファイル

| ファイル | 役割 |
|---|---|
| `src/rules.js` | 盤・合法手・裏返し・パス・終局・まった。画面にも通信にも依存しない |
| `src/rules.test.js` | ルールの自動テスト（乱数1000局）。`node reversi/src/rules.test.js`。確認用の局面 `src/fixtures.js` も作る |
| `src/sfx.js` | 効果音（すべて合成） |
| `src/app.js` | 画面・演出・キャラの演技・進行 |
| `src/shell.html` | 見た目（CSS）と画面の骨組み |
| `build.py` | 1枚の `index.html` に組み立てる：`python3 reversi/build.py` |

キャラは ことばのたね の原画（`tools/game/rig/part_chars.js` ほか）をそのまま読み込む。原画を直すと、ここも組み立て直せば反映される。

## 決まったこと

- 名前は「リバーシ」（「オセロ」は商標のため使わない）。仮題「まるシマリバーシ」
- 呼び名は使わず「くろ」「しろ」で呼ぶ。先手はくろ。対局ごとに子とおばあちゃんでくろを交代
- 取れる枚数は表示しない（多く取れる手が良い手とは限らない）
- 盤は緑・黒い線・4つの星・濃いグレーの枠。置ける場所はミント色のリング、最後に置いた石の下に赤い光（次の手まで残る）
- 石は厚みのある円柱として返す（側面は半分黒・半分白）
- 手加減はおばあちゃん本人がやる（CPU なし）
- キャラ：まるシマ＝子の相棒、めえばあ＝おばあちゃんの相棒、ぽにー＝進行（パス・まった・もういっかい）、かめじい＝審判（はじめ・数え・勝敗）
- 声は段階1〜2は端末の読み上げ。段階3で AivisSpeech／VOICEVOX の合成音声に差し替える
- 確認用：URL の末尾に `#pass`（パス直前）、`#end`（終局直前）
- 盤の外を3秒ながおしで設定（テンポ・光・音量）
