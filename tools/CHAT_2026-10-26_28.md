## アプリ化の方針（10-26 に決定）
- 提供者はうちのあじと同じ口座（UCHINOAJI）。Apple Developer・Google Play Console・Expo の口座がそのまま使える。
- 作戦：Expo の殻で包み、いまの HTML を WebView に読み込む。音声認識だけはネイティブ（WebView では Web Speech API が動かないため）。`game.js` の `hear()` 1か所を差し替えればよい。
